# E2B 模板构建、沙箱启动与暂停恢复从零讲透

一本写给计算机新手的书，讲 E2B 原有的三个操作：**构建模板**（把一个 Dockerfile 做成一张随时能拉起来的虚拟机快照）、**启动沙箱**（从这张快照恢复出一台新机器）、**暂停与恢复**（存盘离场，改天读盘重建）。也讲我们对它们做的修改：搬到 ARM、提速、和新增的快照回滚共存。

- **代码**：[AustinJiangg/e2b-infra](https://github.com/AustinJiangg/e2b-infra) 仓库里的 `0001-adapted-for-arm-architecture.patch`（ARM 适配、启动优化、快照相关修改都在这一份补丁里）和 `e2b-deploy/` 部署脚本。
- **机器**：鲲鹏 920B 与鲲鹏 950 两类 ARM 服务器，openEuler 系统，单节点部署。
- **范围**：三个操作各自怎么做、时间花在哪、我们改了什么、为什么改、改对了的证据。快照回滚本身不展开。

全书围绕一句话展开：**一切皆快照**。构建的终点是拍一张快照；启动从这张快照恢复；暂停在当前状态上再拍一张；恢复又从那一张恢复。构建本身也在这个圈里反复转：每条指令都是“恢复—执行—暂停”。另外两条主线：**只为用到的付费**（内存懒加载、只存改过的部分、层缓存），**固定开销藏在建和拆里**（启动慢在拉起 Firecracker，暂停慢在拆掉它）。

前 4 篇打底：沙箱由什么组成，内存页、缺页、块设备、命名空间这些基础，快照三件套与映射表。之后分四部分：

1. **构建模板**：流水线五个阶段，base 阶段的两次开机，指令、层与缓存，就绪那一刻拍下的最终快照，以及搬到 ARM 改了什么。
2. **启动沙箱**：启动就是恢复，拉起 Firecracker，内存懒加载与预取，磁盘、网络与 envd，时间花在哪，怎样把它压下来。
3. **暂停与恢复**：暂停六步与为什么一定要停沙箱，增量怎么算、250 ms 花在哪，恢复与推迟的成本，ARM 上“读过就算脏”，精确增量。
4. **和快照回滚共存**：回滚动了哪些共用部件，三处被撞坏的地方和修法，全景与修改清单。

约 5.3 万汉字，23 篇，79 张图。

本书只读不练，没有需要动手的实验；文中的代码和命令都是帮助理解的示例片段，不逐函数讲源码。快照回滚详见《E2B 沙箱快照回滚从零讲透》；部署、网络、存储的细节详见《E2B 部署从零讲透》《E2B 沙箱网络从零讲透》《E2B 沙箱存储从零讲透》；逐包读上游源码见《E2B Infra 源码导读》。

## 阅读建议

- **完全的新手**：从头顺着读。第 3、4 篇是概念基础，后面大量用到。
- **只关心某一个操作**：读完第 1～4 篇，直接跳到对应部分。
- **想知道为什么一百多毫秒就能给出一台沙箱**：读第 8、10、12 篇。
- **只关心我们改了什么**：读第 9、15、19～22 篇，再看第 23 篇的修改清单。
- **只关心数字**：启动看第 14 篇，暂停与恢复看第 17、18 篇，精确增量看第 20 篇。
- 每篇末尾有“本篇小结”表格，复习时过一遍小结即可。

## 几个容易出乎意料的事实

| 事实 | 篇 |
|---|---|
| E2B 从不冷启动用户的沙箱：envd 在构建时就已启动、冻进了快照，Sandbox.create 只是让它醒过来 | 8、10 |
| 构建一个模板，本身就是在反复启动和暂停：每条指令一层，每层都是一次“恢复—执行—暂停” | 5、7 |
| 100 路并发下，启动的 82% 时间卡在拉起 Firecracker；加载快照本身只要 29 ms | 14 |
| `ip netns exec` 远不止进网络命名空间，它还偷偷做五件事，其中三件要抢内核全局锁 | 15 |
| 把启动管线整个重写，子进程侧快了 109 ms，父进程侧又赔回 140 ms，合计更慢 | 15 |
| 一台空闲沙箱约占 350 MiB；并发容量先卡在 orchestrator 的 cgroup，而不是大页池 | 12 |
| 暂停一定会停掉沙箱：导出磁盘增量的那个函数，参数之一就是“关掉沙箱” | 16 |
| 什么都没改的暂停也要约 250 ms，真正存状态的只有前 10 ms，其余都在拆机 | 17 |
| 恢复很快，但成本被推迟了：恢复后第一次读 192 MiB 多花约 112 ms | 18 |
| ARM 上注释掉三行代码，让“读过的页”也算脏：改 12 MiB，导出 148 MiB | 19 |
| 只把判据换对还不够：4 MiB 的散写落进 67 个 2 MiB 块，归并后仍是 134 MiB | 20 |
| 构建内存超限的故障，最后表现为 api 一直 503，报错里没有一个字提到内存 | 9 |
| 做过快照回滚存档的沙箱一暂停，数据就丢了一截；第一版验证被 guest 页缓存盖住，假通过 | 22 |
