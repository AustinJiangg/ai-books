# 图的规约

本书的图全部用 Mermaid 写在正文里，没有外部图片。

- 编号按章内出现顺序：图 N-1、图 N-2……；图题放在图下，格式为 `**图 N-M　标题**`。
- 示意图在图题后注明依据，例如"（示意图，依据 DSec §5.2 绘制）"；属于本书推断的结构，图题中标"（推断）"。
- 表题放在表上，格式为 `**表 N-M　标题**`；表注放在表下，以"注："开头。
- 正文引用写作"（见图 N-M）""（见表 N-M）"，跨章同样写章号。
- 图中只放正文已经讲过并标明来源的内容，不在图里引入新事实或新数字。
- 改图后用 `tools/figcheck.sh agent-sandbox` 检查渲染。
