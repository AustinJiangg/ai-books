# 图的规约（DeepInfer 技术手册）

本书所有图均采用 Mermaid 语法内嵌于 Markdown，最终编译为单文件离线 HTML（`html/deepinfer.html`）。

为保证在不同设备（手机、平板、宽屏显示器）以及暗色/亮色模式下均获得清晰美观的渲染效果，所有配图需遵循以下规约。

---

## 1. 硬性指标与排版阈值

| 检查项 | 阈值标准 | 规约原因 |
|---|---|---|
| 自然宽度 | ≤ 1040 px | 正文内容主栏固定为 820 px，最大展开宽度 1100 px，超出将被整体缩放导致字号过小 |
| 自然高度 | ≤ 900 px | 保证单一流程或架构图在主流笔记本屏上一屏读完，避免纵向失真 |
| 节点数量 | ≤ 20 个 | 超过 20 个节点的单图信息过载，应拆解为局部视图或上下游阶段图 |
| 文字溢出与重叠 | 0 | 节点文字严禁超出外框，边标签严禁压盖其他连线或箭头 |
| 标签字符长度 | 汉字 ≤ 14，英文 ≤ 28 | 换行使用 `<br/>` 手工断句，严禁依赖 Mermaid 自动分词折行 |

---

## 2. 常用图类型规范

### 2.1 流程图 (`flowchart TB` / `flowchart LR`)
- 默认采用 `flowchart TB`；横向时序流（≤ 6 个阶段）可采用 `flowchart LR`。
- 节点命名规范：语义化大写字母组合，如 `SCHED["调度器 Scheduler"]`、`GPU_RUN["Worker 前向计算"]`。
- 节点标签全部使用 `["..."]` 包含，禁止裸写特殊字符（如括号、竖线、引号）。
- 复杂流采用 `subgraph` 分层，并在子图内显式声明 `direction TB`。

### 2.2 时序图 (`sequenceDiagram`)
- 参与者（`participant`）数量 ≤ 5 个（如 `Client`、`LLMEngine`、`Scheduler`、`Worker`、`GPU Device`）。
- 交互消息步数 ≤ 12 步，避免出现无休止的时序滚动条。
- 激活态必须成对闭合（`activate` 与 `deactivate`）。

### 2.3 状态机图
- 状态少于 5 个时可用 `stateDiagram-v2`；
- 复杂状态机（如 Sequence 的 7 种状态流转）一律改用 `flowchart TB`，状态使用圆角矩形 `S(["RUNNING"])`，连线上使用简短动词或编号（①②③），并在图下方辅以状态转移表格。

### 2.4 内存与数据结构布局
- 字节布局、块映射表、张量维度形状图等，优先使用 ```text ASCII 字符图进行排版，字体等宽对齐，直观严谨。
