# 第 2 章　指针、数组与引用 ★

指针和引用是 C++ 与 Java 差别最大的地方：Java 隐藏了地址，C++ 让你直接操作地址。这一章是后面所有内容的基础，务必读懂。

## 2.1　内存与地址

每个变量都存放在内存中的某个位置，这个位置的编号叫**地址**。

- `&x`：取 x 的地址。
- 指针：专门存放地址的变量。
- `*p`：解引用，访问 p 所指向的那个变量。

```cpp
int x = 10;
int* p = &x;     // p 存放 x 的地址，读作“p 是指向 int 的指针”
cout << *p;      // 输出：10
*p = 20;         // 通过指针修改 x
cout << x;       // 输出：20
```

可以这样理解：x 是一个房间，`&x` 是房间号，p 是一张写着房间号的纸条，`*p` 是按纸条走进那个房间。

**易错**：`*` 在声明和表达式中的含义不同。

- 声明中 `int* p` 的 `*` 表示“p 是指针”。
- 表达式中 `*p` 的 `*` 表示“取 p 指向的值”。
- `int* p, q;` 中只有 p 是指针，q 是普通 int。

## 2.2　空指针 nullptr

C++11 用 `nullptr` 表示空指针，取代 C 中的 `NULL` 和 `0`。

```cpp
int* p = nullptr;   // 不指向任何对象
if (p != nullptr) cout << *p;  // 解引用前先检查
```

- 解引用空指针是**未定义行为**，通常导致程序崩溃。
- **野指针**：未初始化的指针，或指向已释放内存的指针（悬空指针），同样不能解引用。
- 使用 `nullptr` 而不用 `0`，是因为 `0` 是 int，在函数重载时会产生歧义。

## 2.3　数组

```cpp
int a[5] = {1, 2, 3};    // 未给出的元素为 0：1 2 3 0 0
int b[] {1, 2, 3};       // 大小由初始值决定，为 3
int c[2][3] = {{1,2,3},{4,5,6}};  // 二维数组
```

- 数组大小必须是常量表达式（编译时已知）。
- 下标从 0 开始，`a[5]` 越界，C++ **不检查越界**，不会像 Java 那样抛异常，而是产生未定义行为。
- 数组不能整体赋值：`a = b;` 是错误的。
- 求元素个数：`sizeof(a) / sizeof(a[0])`。

## 2.4　指针与数组的关系

数组名在大多数表达式中会**自动转换为指向首元素的指针**。

```cpp
int a[5] {10, 20, 30, 40, 50};
int* p = a;          // 等价于 p = &a[0]
cout << *p;          // 10
cout << *(p + 2);    // 30，p+2 指向 a[2]
cout << p[3];        // 40，p[i] 等价于 *(p+i)
cout << *a + 1;      // 11，先取 *a 得 10，再加 1
cout << *(a + 1);    // 20
```

**指针运算**：`p + 1` 不是地址加 1 字节，而是移到下一个元素，即加 `sizeof(int)` 字节。两个指向同一数组的指针相减，得到它们之间相隔的元素个数。

```cpp
int* q = &a[4];
cout << q - p;       // 4
```

**数组名与指针的区别**：

- `sizeof(a)` 是整个数组的大小（20 字节），`sizeof(p)` 是指针的大小（通常 8 字节）。
- 数组名不能被赋值，`a++` 是错误的；指针可以，`p++` 是正确的。

**数组作函数参数会退化为指针**：

```cpp
void f(int arr[], int n) {   // 等价于 int* arr
    // sizeof(arr) 是指针大小，不是数组大小！
    for (int i = 0; i < n; ++i) arr[i] *= 2;  // 修改的是原数组
}
```

所以传数组时必须另外传长度，并且函数内的修改会影响调用者的数组。

## 2.5　C 风格字符串

C 风格字符串是以 `'\0'` 结尾的 char 数组。

```cpp
char s1[] = "hello";     // 6 个元素，含 '\0'
const char* s2 = "hello"; // 指向字符串字面量，不能修改其内容
// 常用函数（#include <cstring>）：strlen、strcpy、strcat、strcmp
cout << strlen(s1);      // 5，不计 '\0'
cout << sizeof(s1);      // 6
```

**易错**：两个 C 风格字符串不能用 `==` 比较内容，`==` 比较的是地址，要用 `strcmp`。C++ 中尽量用 `std::string`（见 2.11）。

## 2.6　const 与指针（必考）

关键是看 `const` 在 `*` 的左边还是右边。

```cpp
int x = 1, y = 2;

const int* p1 = &x;    // 指向常量的指针：不能通过 p1 改 x，但 p1 可以指向别处
// *p1 = 5;  错误
p1 = &y;               // 可以

int* const p2 = &x;    // 常量指针：p2 本身不能改，但可以通过它改 x
*p2 = 5;               // 可以
// p2 = &y;  错误

const int* const p3 = &x;  // 两者都不能改
```

**记法**：从变量名往左读。

- `int* const p2`：p2 是 const 的，它是指向 int 的指针 → 指针本身不可变。
- `const int* p1`（也可写作 `int const* p1`）：p1 是指针，指向 const int → 指向的内容不可变。

| 声明 | 能否改 \*p | 能否改 p |
| --- | --- | --- |
| `int* p` | 能 | 能 |
| `const int* p` | 不能 | 能 |
| `int* const p` | 能 | 不能 |
| `const int* const p` | 不能 | 不能 |

另外，普通指针不能指向 const 变量：`const int c = 1; int* p = &c;` 是错误的，因为这样就能通过 p 修改常量了。

## 2.7　引用（必考）

**引用是变量的别名**。定义时必须初始化，之后永远绑定这个变量，不能改为引用别的变量。

```cpp
int x = 10;
int& r = x;      // r 是 x 的别名
r = 20;          // 等于 x = 20
cout << x;       // 20

int y = 30;
r = y;           // 不是让 r 引用 y！而是把 y 的值赋给 x
cout << x;       // 30
```

**引用与指针的对比**

| 比较项 | 引用 | 指针 |
| --- | --- | --- |
| 是否必须初始化 | 必须 | 不必须 |
| 能否为空 | 不能（没有“空引用”） | 可以为 `nullptr` |
| 能否改变指向 | 不能，一生绑定一个对象 | 可以 |
| 访问方式 | 直接用名字 | 要用 `*` 或 `->` |
| 是否占用独立对象 | 语言上不是对象 | 是一个独立的变量 |
| 有无多级 | 没有“引用的引用” | 有 `int**` |

## 2.8　引用作函数参数

这是引用最主要的用途。比较三种传参方式：

```cpp
void swap1(int a, int b)   { int t = a; a = b; b = t; }   // 值传递
void swap2(int* a, int* b) { int t = *a; *a = *b; *b = t; } // 指针传递
void swap3(int& a, int& b) { int t = a; a = b; b = t; }   // 引用传递

int main() {
    int x = 1, y = 2;
    swap1(x, y);   cout << x << y;   // 12，没交换：只交换了副本
    swap2(&x, &y); cout << x << y;   // 21，交换了
    swap3(x, y);   cout << x << y;   // 12，又换回来了
}
```

- 值传递：形参是实参的副本，函数内修改不影响实参。
- 指针传递：传的是地址，通过 `*` 修改实参。
- 引用传递：形参就是实参本身，写法简洁，不需要 `&` 和 `*`。

**const 引用作参数**：既避免拷贝（对大对象很重要），又保证不修改。

```cpp
void print(const string& s) { cout << s; }  // 不拷贝，也不能改 s
print("hello");   // 可以：const 引用能绑定到临时对象
```

**易错**：非 const 引用不能绑定到字面量或临时值。

```cpp
int& r1 = 10;          // 错误
const int& r2 = 10;    // 可以
void f(int& x);
f(5);                  // 错误
```

## 2.9　引用作函数返回值

返回引用意味着返回的是对象本身，调用表达式可以放在赋值号左边。

```cpp
int arr[3] {1, 2, 3};
int& at(int i) { return arr[i]; }

at(1) = 100;      // 直接修改 arr[1]
cout << arr[1];   // 100
```

**易错（必考）：不能返回局部变量的引用或指针**。函数结束后局部变量被销毁，引用会悬空。

```cpp
int& bad() {
    int x = 5;
    return x;     // 错误：x 在函数返回后就不存在了
}
```

可以返回引用的情况：全局变量、`static` 局部变量、通过引用或指针传入的参数、类的成员（返回 `*this` 等）。

## 2.10　动态内存：new 与 delete

局部变量在**栈**上，函数结束自动销毁；用 `new` 分配的对象在**堆**（自由存储区）上，必须手动 `delete`。C++ 没有 Java 那样的垃圾回收。

```cpp
int* p = new int;        // 分配一个 int，值不确定
int* q = new int(5);     // 分配并初始化为 5
int* r = new int{5};     // 同上，C++11 写法
delete p;
delete q;
delete r;

int n = 10;
int* arr = new int[n];   // 动态数组，n 可以是变量
int* arr2 = new int[n]{};  // 全部初始化为 0
delete[] arr;            // 释放数组必须用 delete[]
delete[] arr2;
```

**new/delete 与 malloc/free 的区别（常考简答）**

- `new`/`delete` 是运算符，`malloc`/`free` 是库函数。
- `new` 会调用构造函数，`delete` 会调用析构函数；`malloc`/`free` 不会。
- `new` 返回正确类型的指针，不需要强制转换；`malloc` 返回 `void*`。
- `new` 失败时抛出 `bad_alloc` 异常；`malloc` 失败时返回 `NULL`。
- `new` 自动计算所需大小，`malloc` 需要手动传字节数。

**常见错误**

- **内存泄漏**：`new` 了忘记 `delete`。
- **重复释放**：同一指针 `delete` 两次。
- **悬空指针**：`delete p;` 之后又使用 `*p`。建议释放后令 `p = nullptr;`（`delete nullptr` 是安全的）。
- **混用**：`new[]` 配 `delete`，或 `new` 配 `delete[]`，都是未定义行为。

## 2.11　std::string

`string` 是标准库提供的字符串类（`#include <string>`），自动管理内存，使用方式接近 Java 的 String，但 C++ 的 string **是可修改的**。

```cpp
string s1 = "hello";
string s2 {"world"};
string s3 = s1 + " " + s2;   // 拼接：hello world
s1 += "!";                    // s1 变为 hello!
cout << s3.size();            // 11（也可以用 length()）
cout << s3[0];                // h
s3[0] = 'H';                  // 可以修改：Hello world
if (s1 == "hello!") { }       // == 比较的是内容（与 C 字符串、Java 不同）

cout << s3.substr(6, 5);      // world：从下标 6 开始取 5 个字符
cout << s3.find("world");     // 6；找不到返回 string::npos
s3.insert(5, ",");            // Hello, world
s3.erase(5, 1);               // 删除下标 5 开始的 1 个字符

string line;
cin >> line;                  // 读到空白为止
getline(cin, line);           // 读一整行
const char* cs = s1.c_str();  // 转为 C 风格字符串
```

**易错**：`string s = "a" + "b";` 是错误的，两个字符串字面量是 `const char*`，不能相加；至少一边是 string 才行：`string("a") + "b"`。

## 2.12　右值引用入门（C++11）

- **左值**：有名字、可以取地址的对象，如变量 `x`。
- **右值**：临时值，如 `10`、`x + 1`、函数返回的临时对象。
- `int&` 是左值引用，只能绑定左值；`int&&` 是**右值引用**，只能绑定右值。

```cpp
int x = 5;
int& a = x;        // 可以
int&& b = 10;      // 可以：绑定到临时值
int&& c = x + 1;   // 可以
// int&& d = x;    错误：x 是左值
int&& e = std::move(x);  // 可以：std::move 把左值转换为右值
```

右值引用的用途是实现**移动语义**：既然临时对象马上就要销毁，就可以直接“偷走”它的资源，而不必拷贝。第 6 章会详细讲。

## 2.13　本章小结

- `&x` 取地址，`*p` 解引用；数组名会转换为首元素指针，`p[i]` 等价于 `*(p+i)`。
- 数组作参数会退化为指针，函数内 `sizeof` 得不到数组大小。
- `const int*` 内容不可改，`int* const` 指针不可改。
- 引用是别名：必须初始化、不能为空、不能换绑定。
- 引用传参可以修改实参；`const&` 传参避免拷贝且可绑定临时值。
- 不能返回局部变量的引用。
- `new` 配 `delete`，`new[]` 配 `delete[]`；`new` 会调用构造函数。
