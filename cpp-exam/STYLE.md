# 凡例

1. 章标题写作“第 N 章　标题”，节写作“N.M　标题”，章号、节号后用全角空格。小节以下用段首加粗短语提示层次。
2. 章标题后的 ★ ☆ ○ 表示重要程度：★ 必考，☆ 常考，○ 了解。
3. 所有代码默认已写 `#include <iostream>` 和 `using namespace std;`，需要额外头文件时在正文或代码注释里说明。
4. 代码注释中“// 输出：”后面是该行的运行结果。
5. **易错** 标注考试中的常见陷阱；**必考** 标注几乎每年都考的点。
6. 术语以 Stroustrup《C++程序设计语言》（第 4 版）中文版的译名为准，例如“名字空间”“列表初始化”“移动语义”。
7. 每章末尾有“本章小结”，只复述本章已讲过的结论，不引入新内容。
8. 代码按 C++11 标准编写；少数 C++14 及以后的写法（如 `make_unique`）在出现处注明。
