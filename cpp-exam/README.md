# C++ 期末笔试突击手册

> **v0.1.0** · 2026-10-07 · 江路路

## 怎么读

- 只有几天：第 0 章 → 第 2、5、6、7、8 章 → 第 12 章。
- 每章末尾有“本章小结”，考前过一遍小结即可。
- 读程序题一定要自己在草稿纸上“执行”一遍，再对照书里的分析。
- 本书不覆盖上机考试；上机请自己动手练。
