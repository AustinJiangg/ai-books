## 0.2　笔试常见题型

1. **选择题、填空题**：考概念细节。例如：哪个运算符不能重载、析构函数能否有参数、`const` 修饰的位置含义。
2. **读程序写结果**：最能拉开分数。常考构造/析构的顺序、拷贝构造在何时被调用、虚函数最终调用哪个版本、`static` 变量的值、引用和指针修改了谁。
3. **改错题**：常见错误有访问 `private` 成员、`const` 成员函数修改数据、漏写 `virtual`、`delete` 与 `delete[]` 混用、返回局部变量的引用。
4. **程序填空或编程题**：补全一个类、写运算符重载、写一个抽象基类加若干派生类。

## 0.3　读程序题的答题方法

- 从 `main` 开始逐行执行，**不要凭印象跳步**。
- 在草稿纸上为每个对象画一个方框，写上成员的当前值。
- 每创建一个对象就记一笔“构造”，每个对象离开作用域时记一笔“析构”。
- 同一作用域里的局部对象，**析构顺序与构造顺序相反**。
- 遇到函数调用，先看参数是**值传递**（会拷贝）、**引用传递**（不拷贝）还是**指针传递**。
- 遇到通过指针或引用调用成员函数，先问：这个函数是不是 `virtual`？
