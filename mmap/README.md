# mmap 从零讲透

一本写给计算机新手的 mmap 教程。读者只需要会一点 C、能看懂简单的程序，不要求学过操作系统。从“程序是怎么读一个文件的”讲起，依次铺垫系统调用、虚拟内存、缺页异常和页缓存，再正式讲 mmap 的用法、写时复制、匿名映射、落盘与 SIGBUS、性能取舍，最后进入内核实现和真实系统（动态链接器、数据库、设备映射、Firecracker、userfaultfd）。约 4 万字（另有大量示例代码），12 篇。

代码使用 C 语言 + Linux；涉及硬件细节时以 ARM64（aarch64）为例，必要时对比 x86。每篇都有可以自己动手跑的小实验。

## 怎么读

- 第 1～5 篇是概念地基，还没出现 mmap 本身，但后面每一篇都建立在它们之上，建议按顺序读。
- 第 6～9 篇是核心用法；只想学会用 mmap，读完这四篇即可。
- 第 10～12 篇面向想深入的读者：性能分析、内核源码路径和真实系统里的用法。
- 每篇末尾有“本篇小结”表格，复习时过一遍小结即可。
- 文中的 C 示例程序都是完整可编译的，建议边读边在 Linux 上跑一遍；输出里的地址、计数等数字随机器而异，看量级即可。第 1 篇里直接执行 `svc` 指令的程序只能在 ARM64 上编译。
